# Exact environment for reproducing the reported numbers.
#
# scikit-learn is pinned to 1.6.1 deliberately. Per-teacher logits are produced
# by multinomial logistic probes; the `multi_class` parameter was deprecated in
# scikit-learn 1.5 and removed in 1.7. On the binary benchmark (MHIST) the
# multinomial and standard binary parameterisations differ, so a later version
# silently produces different logits for that dataset. We verified that 1.6.1
# with multi_class='multinomial' reproduces the released MHIST logits exactly.
#
# On the multiclass benchmarks, regeneration reproduces accuracy to within one
# sample on BRACS (1/3969) and two on SICAPv2 (2/12081). This is lbfgs
# convergence variation across library builds, not a difference in protocol.
# verify_claims.py therefore uses a tolerance of 0.05 percentage points.
